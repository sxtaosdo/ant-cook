棋盘编辑器

画食物图案 → 配底部待选区 → 验证 → 保存草稿或生成候选

完成棋盘，配置待选区 ↓
第一次使用：从一块方块开始
  1. 在上方画出食物；点“完成棋盘，配置待选区 ↓”，首次按各色总数生成普通方块。也可以直接点下方“载入普通示例”。
  2. 点击彩色方块，在“方块编辑”中设置颜色和数字；统计卡对照“棋盘 / 待选”数量。后续改棋盘会保留手调方块，需要替换时点“自动填充待选区”。
  3. 勾选“问号方块”即可隐藏；编辑时保留真实颜色和数字供修改，试玩时按游戏规则揭示。
  4. 点“检查关卡”，再点“试玩”。试玩中点击列首方块，搬完全部食物后会提示通关。
  5. 用下方“保存整份草稿”保存图案、方块及规则；之后用“打开草稿”继续编辑。

“方块编辑”下的“一起出发”面板中先新建或选择组，再点方块加入或移出；同组方块由带组号的线连接，线色、线型与符号区分各组，保留方块的游戏底色。“全部删除”只清下方方块及关联，可撤销，重新进入不会自动长回。钥匙和候选编译在折叠设置中。下载连体／问号／钥匙教学草稿后用“打开草稿”查看。

试玩只使用临时内存，不写玩家存档或正式关卡；游戏画面和动画仍需单独验证。
